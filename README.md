## About the entry

A single-line, self-deprecating pickup line contrasting messy human biology with superior machine engineering—written fresh to charm a robot or an AI while landing a clean stand-up punch under 200 characters.

## Run it

Runs on Node 22+ (and Node 24) using only the Node standard library and erasable TypeScript:

```sh
node main.ts
```

By default, `main.ts` writes the single-line UTF-8 entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when `MAKEFUN_OUTPUT_DIR` is set), exits `0` silently on success, and exits non-zero on failure. In grading, the runner executes `node /bot/main.ts`.
